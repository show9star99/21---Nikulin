#  Информационная система: ИС Университет
> **Предметная область:** Университет

## 1. Описание проекта
Данный проект представляет собой прототип информационной системы (ИС) для автоматизации учета успеваемости и управлении учебным процессом. 
Система позволяет структурировать хранение данных о студентах, преподавателях и дисциплинах, а также быстро получать аналитическую информацию через SQL-запросы (например, рейтинг студентов или отчеты по сессии).

##  2. Техническое задание (ТЗ) вкратце
*   **Цель:** Перейти от бумажного учета (журналов и ведомостей) к автоматизированной базе данных на SQLite.
*   **Основные функции:**
    I. Регистрация новых записей (студенты, преподаватели, учебные дисциплины).
    II. Поиск данных по заданным критериям (например, поиск студентов по группе или фамилии).
    III. Формирование итоговых отчетов за период (например, поиск студентов по группе или фамилии).
*   **Требования к БД:** Минимум 4 связанные таблицы, соблюдение целостности данных.

##  3. Структура базы данных (ER-схема)
Проект базируется на следующих сущностях:
1.  **[Группы]** — хранит данные о группах(группа, студенты, кафедра).
2.  **[Студенты]** — хранит данные о студентах(ФИО, группа, кафедра).
3.  **[Кафедры]** — отвечает за данные о преподавателях (ФИО, кафедра, ученая степень).
3.  **[Расписание]** — содержит перечень учебных предметов и их расписание.

*Скриншот ER-диаграммы находится в папке `/diagrams`.*

##  4. Реализованные SQL-запросы
В рамках проекта подготовлены сценарии для:
*   Подсчета общего количества студентов в разрезе групп.
*   Выборки данных с использованием `JOIN` (объединение таблиц студентов, дисциплин и оценок).
*   Фильтрации данных по условию (например, средний балл > 4.0 или отображение должников).

##  Структура репозитория
*   `/data` — файл базы данных `project.db`.
*   `/sql` — скрипты создания таблиц (`create.sql`) и тестовые данные (`insert.sql`).
*   `/diagrams` — графическая схема базы данных.
*   `queries.sql` — файл с примерами сложных запросов.

##  Как запустить (Инструкция)
1.  **Склонируйте репозиторий:**
    ```bash
    git clone [https://github.com/ваш_логин/21---Nikulin.git](https://github.com/ваш_логин/21---Nikulin.git)
    cd 21---Nikulin/project
    ```

2.  **Настройте окружение (опционально):**
    Убедитесь, что у вас установлен Python 3.10 или выше.

3.  **Запустите приложение:**
    Из корневой папки проекта (`project`) выполните команду:
    ```bash
    python src/main.py
    ```

4.  **Использование:**
    При первом запуске программа автоматически создаст файл `university.db` на основе `schema.sql`. Используйте консольное меню для навигации:
    * Нажмите `1` для просмотра списка студентов с их группами.
    * Нажмите `2` для регистрации нового студента.
    * Нажмите `0` для выхода.
