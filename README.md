# Информационная система: ИС Университет
> **Предметная область:** Университет
> **Разработчик:** Группа 21ИС-9-24, Никулин Никита

## 1. Описание проекта
Данный проект представляет собой прототип информационной системы (ИС) для автоматизации учета успеваемости и управления учебным процессом. 
Система позволяет структурировать хранение данных о студентах, преподавателях и дисциплинах, а также быстро получать аналитическую информацию через SQL-запросы.

## 2. Техническое задание (ТЗ) вкратце
* **Цель:** Перейти от бумажного учета к автоматизированной базе данных на SQLite.
* **Основные функции:**
    1. Регистрация новых записей (студенты, преподаватели, дисциплины).
    2. Поиск данных по заданным критериям (группа, фамилия).
    3. Формирование итоговых отчетов (статистика успеваемости, списки должников).
* **Требования к БД:** Минимум 4 связанные таблицы, соблюдение целостности данных.

## 3. Структура базы данных (ER-схема)
Проект базируется на следующих сущностях:
1. **[Группы]** — информация об учебных группах.
2. **[Студенты]** — персональные данные студентов и их принадлежность к группам.
3. **[Преподаватели]** — данные о преподавательском составе (ФИО, кафедра, ученая степень).
4. **[Расписание/Дисциплины]** — перечень учебных предметов и график занятий.

*Скриншот ER-диаграммы находится в папке `/docs`.*

## 4. Реализованные SQL-запросы
В рамках проекта подготовлены сценарии для:
* Подсчета общего количества студентов в разрезе групп.
* Выборки данных с использованием `JOIN` (объединение таблиц студентов, дисциплин и оценок).
* Фильтрации данных по условию (например, средний балл > 4.0).

## Структура репозитория
* `/database` — файл базы данных `university.db` и `schema.sql`.
* `/src` — основные скрипты, включая `main.py`.
* `/docs` — графическая схема базы данных `er_diagram.png`.
* `services.py` — модуль для добавления новых объектов в БД.

## Как запустить (Инструкция)
1. **Склонируйте репозиторий:**
    ```bash
    git clone [https://github.com/ваш_логин/21---Nikulin.git](https://github.com/ваш_логин/21---Nikulin.git)
    cd 21---Nikulin
    ```

2. **Настройте окружение:**
    Убедитесь, что у вас установлен Python 3.10 или выше.

3. **Запустите приложение:**
    ```bash
    python src/main.py
    ```

4. **Использование:**
    При первом запуске программа автоматически создаст файл `university.db`.
    * Нажмите `1` для просмотра списка студентов.
    * Нажмите `2` для регистрации нового студента.
    * Нажмите `3 для удаление студента из списка.
    * Нажмите `0` для выхода.
